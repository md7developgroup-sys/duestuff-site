# duestuff-site

Публичный сайт `duestuff.com`: страница приложения и политика конфиденциальности.
Публикуется GitHub Pages из ветки `main`, корень репозитория.

```
index.md            → https://duestuff.com/
privacy/index.md    → https://duestuff.com/privacy/
CNAME               → duestuff.com
```

## Правило, которое нельзя нарушать

**Источник правды для политики — файл `docs/privacy-policy.md` в приватном репозитории
приложения.** Здесь лежит его копия для публикации: тот же текст без внутренней памятки
по анкете Data Safety, которой на публичной странице делать нечего.

Меняется политика — правится сначала исходный файл, потом эта копия, и обязательно
обновляется дата в шапке обоих. Разошедшиеся тексты хуже, чем один устаревший: политика
и есть обещание продукта, а адрес страницы зашит внутрь выпущенных версий приложения
(`PrivacyPolicy.URL`) и в карточку Google Play.

## Настройка (делается один раз)

1. Settings → Pages → Source: Deploy from a branch, ветка `main`, папка `/ (root)`.
2. Custom domain: `duestuff.com`. Файл `CNAME` в репозитории уже есть.
3. DNS. Домен зарегистрирован в Namecheap 12 августа 2026, заявка на перенос в GoDaddy
   ждёт снятия 60-дневного запрета ICANN и выполнится 11 октября 2026. Смена регистратора
   **не переносит DNS-записи**, поэтому заводить их в панели Namecheap не надо — только
   там, где они останутся после переезда. Записи:
   - четыре записи `A` для `@` на адреса GitHub Pages;
   - `CNAME` для `www` на `<аккаунт>.github.io.`;
   - удалить записи парковки Namecheap (`parkingpage.namecheap.com`, URL Redirect),
     иначе домен продолжит показывать заглушку регистратора.
4. Дождаться сертификата и включить **Enforce HTTPS**. Google Play не принимает
   политику, доступную только по `http`.
