# duestuff-site

Публичный сайт `duestuff.com`: страница приложения и политика конфиденциальности.
Публикуется GitHub Pages из ветки `main`, корень репозитория.

```
index.md                → https://duestuff.com/
privacy/index.md        → https://duestuff.com/privacy/          (docs/privacy-policy.md)
privacy/en/index.md     → https://duestuff.com/privacy/en/       (docs/privacy-policy.en.md)
delete-account/index.md → https://duestuff.com/delete-account/   (docs/account-deletion.md)
_layouts/default.html   → вёрстка всех страниц
CNAME                   → duestuff.com
```

## Правило, которое нельзя нарушать

**Источник правды для политики — файл `docs/privacy-policy.md` в приватном репозитории
приложения.** Здесь лежит его копия для публикации: тот же текст без внутренней памятки
по анкете Data Safety, которой на публичной странице делать нечего.

Меняется политика — правится сначала исходный файл, потом эта копия, и обязательно
обновляется дата в шапке обоих. Разошедшиеся тексты хуже, чем один устаревший: политика
и есть обещание продукта, а адрес страницы зашит внутрь выпущенных версий приложения
(`PrivacyPolicy.URL`) и в карточку Google Play.

Проверено на себе 16 августа 2026: копия отставала на два дня и утверждала обратное
тому, что делало приложение.

## Вёрстка своя

Темы Jekyll здесь нет. Штатная `jekyll-theme-minimal` дорисовывала к каждой странице
кнопку «View the Project on GitHub», подпись «This project is maintained by …» и
«Hosted on GitHub Pages» — то есть ссылки с юридического документа на инфраструктуру
разработчика, написанные не нами.

`_layouts/default.html` не тянет ни одного внешнего ресурса: ни шрифтов, ни аналитики,
ни CDN. Страница о приватности, загружающая чужой скрипт, противоречит собственному
тексту.

## Настройка и DNS

Записаны в приватном репозитории приложения — `docs/release.md`, раздел «Документы».
Здесь их нет намеренно: репозиторий публичный, а регистратор домена, план переноса
и состав DNS-записей читателю сайта знать незачем.
